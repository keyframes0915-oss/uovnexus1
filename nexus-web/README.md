# UoV Nexus — Career Fair 2026

This is a dependency-free, editable single-page website. Open `index.html` directly in a modern browser, or serve this folder with any local static web server.

## Main files

- `index.html` — content and page structure
- `style.css` — responsive design, visual system and animations
- `main.js` — preloader, mobile navigation and reveal effects

## Adding the supplied assets

The referenced ChatGPT upload did not transfer into this workspace. Once the original files are available, create these folders and use the following replacements in `index.html`:

- Put the UoV Nexus logo in `assets/uov-nexus-logo.png` and replace the text/mark instances where a full logo is preferred.
- Put organizer portraits in `assets/portraits/` and replace the two `.portrait.placeholder` blocks with `<img>` elements using the original portrait filenames.
- Add the proposal’s official contact information to the contact section; the design intentionally avoids fabricated email addresses, phone numbers, venue or dates.

The ID-card preloader is fully functional and uses an editable CSS-built logo treatment, so it remains polished before the source logo is inserted.
